# Codename "Mana-Chrome"
This extension allows you to fill out Managed Quizzes on Google Forms. This extension has been forked from the original repo, which works on firefox, I used ai to port the extension to chromium based browsers, if I ever get interested, I might port it back to firefox at a later date.

### Note: Grab This Extension along side with this one: https://chromewebstore.google.com/detail/bhchdcejhohfmigjafbampogmaanbfkg?utm_source=item-share-cb
also turn on the setting in the user agent manager to latest chromium os version 

### Why Name Change????
I wanted a name to distinguish this repo from the original one, also it kind of sounds like monochrome (hahahahahahaha, laugh now)

### Install manually
Grab the code with git clone or just download a zip file with the big green button on the screen, then in your chromium based browser go to chrome://extensions and turn on developer mode, then click Load unpacked and then go to the folder where you extracted the zip file and open it, and boom you have your extension
